# DM PICKER Data

[DM PICKER](https://github.com/eun-yeon/DmPicker)가 내려받는 곡 데이터입니다.

DJMAX.GG의 곡 정보가 바뀌면 자동으로 새 릴리스가 올라오고, DM PICKER는 실행 중에 바뀐 부분만 받아 적용합니다. 이 저장소의 파일은 직접 고치지 않습니다.

## 릴리스 파일

| 파일 | 내용 |
| --- | --- |
| `manifest.json` | 버전과 각 파일의 SHA-256 |
| `core.json` | 곡 이름, 작곡가, DLC, BPM, 장르, 검색어, 자켓 해시 |
| `dynamic.json` | 인게임 레벨, 서열표, 패턴 특성 |
| `jackets.zip` | 128px 곡 자켓 |

## 데이터 출처

- 곡 정보·검색어: [DJMAX.GG](https://djmax.gg)
- 서열표: [V-Archive](https://v-archive.net)
- 패턴 특성: [행이봇](https://xn--7n3br4q8ll.com)
- 패턴 태그: [로페봇](https://xn--2o2bk9ff9x.com)

## 권리

DM PICKER와 이 데이터는 NEOWIZ와 관련 없는 비공식 프로젝트입니다.

DJMAX, DJMAX RESPECT V는 NEOWIZ의 상표입니다.
곡 자켓 이미지의 저작권은 NEOWIZ와 각 곡·콜라보레이션의 권리자에게 있습니다.
